# Буквено приключение — бележки за разработка

Образователна PWA игра за деца 3–7 г.: писане на цифрите 0–9 и главните букви А–Я
(30 букви) с пръст/стилус, с оценка, звук, точки, награди и минигри.
Принцип: „Играя, а междувременно се уча да пиша“ — не „решавам упражнения“.

## Команди

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # vitest: scoring + progress
npm run lint    # tsc --noEmit
npm run build   # статичен export в out/ + офлайн списък в out/sw.js
```

## Архитектура

- `src/lib/types.ts` — всички типове (Point, Stroke, StrokeTemplate, CharacterLesson, WritingResult, PlayerProgress…).
- `src/data/` — само данни: `alphabet.ts`, `numbers.ts`, `words.ts` (думи/картинки — сменят се тук),
  `strokeTemplates/` (шаблони в квадрат 0..100, y надолу, букви между y=10 и y=90), `rewards.ts`, `games.ts`, `lessons.ts` (нива).
- `src/config/` — всички настройваеми числа: `scoring.ts` (прагове, толеранси), `points.ts`, `mascot.ts`, `app.ts` (името на приложението).
- `src/content/phrases.ts` — **всеки** текст, който детето вижда или чува. Не пиши фрази в компонентите.
- `src/services/` — `scoring.ts` (локално оценяване), `speech.ts` (слой над Web Speech / записани файлове),
  `sounds.ts` (Web Audio синтез), `progress.ts` и `rewards.ts` (чисти функции).
- `src/store/gameStore.ts` — Zustand + localStorage (ръчна хидратация след монтиране).
- `src/components/game/` — `WritingCanvas`, `StrokeGuide`, `useWritingExercise` (цялата логика на опит: зелено/червено,
  точки, подсказка след 2 грешки, демонстрация след 3), `Mascot`, `RewardAnimation`…
- `src/components/games/` — обща механика: `ChoiceGame` (избор), `WriteRoundGame` (писане + „Буквен път“).

## Правила

- TypeScript без `any`; не дублирай логика — екраните ползват `useWritingExercise`, `ChoiceGame`, `WriteRoundGame`.
- Без hardcode на уроци, текстове, аудио или прагове в UI компонентите.
- Детски UX: огромни бутони, минимум текст, без наказващи съобщения, без отнемане на точки, без външни линкове,
  без реклами/tracking. Родителската зона е зад задача „Колко е a + b?“ или 3 сек. задържане.
- `touch-action: none` само върху полето за писане.
- Без мрежови заявки при писане; оценяването е изцяло локално.

## Оценяване (накратко)

Движенията на детето и шаблонът се resample-ват до точки през 2 единици. Оценката (0–100) комбинира
покритие на шаблона, точност на мастилото, посока и брой движения; липсващо парче от шаблона
(напр. чертичката на А) или излишно парче мастило (напр. 8 вместо 3) я свалят рязко.
При easy/normal се сравнява и по място, и само по форма (bbox нормализация); при hard — само по форма.
Всяка промяна на праговете трябва да минава `npm test` (включва матрица на объркване за А, Б, О, М, 1, 2, 3, 8).
