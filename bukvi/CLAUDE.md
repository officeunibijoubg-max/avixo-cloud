# Буквено приключение — бележки за разработка

Образователна PWA игра за деца 3–7 г.: писане на цифрите 0–9 и главните букви А–Я
(30 букви) с пръст/стилус, с оценка, звук, монети, награди и минигри.
Принцип: „Играя, а междувременно се уча да пиша“ — не „решавам упражнения“.
Писането е центърът на играта; основният цикъл е „Продължи“ по пътя на обучение.

## Команди

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # vitest: оценяване, прогрес, отключване, магазин, говор
npm run lint    # tsc --noEmit
npm run build   # статичен export в out/ + офлайн списък в out/sw.js
```

Хостинг: Vercel (Root Directory `bukvi`, настройките са във `vercel.json`); всяко сливане в `main` се качва само.

## Архитектура

- `src/lib/types.ts` — всички типове (Point, Stroke, StrokeTemplate, CharacterLesson, WritingResult, PlayerProgress, Settings).
- `src/data/` — само данни: `alphabet.ts`, `numbers.ts`, `words.ts` (думи, ключове на илюстрации, звукове „Бъ“),
  `strokeTemplates/` (шаблони в квадрат 0..100, y надолу, букви между y=10 и y=90), `adventure.ts` (световете на картата),
  `shop.ts` (магазин и стикери), `similar.ts` (приличащи букви за слушане), `games.ts`, `lessons.ts` (групи за нивото).
- `src/config/` — настройваеми числа: `scoring.ts` (прагове, толеранси), `points.ts` (монети), `speech.ts`
  (как звуковете се подават на синтезатора), `mascot.ts`, `app.ts` (името на приложението).
- `src/content/phrases.ts` — **всеки** текст, който детето вижда или чува. Не пиши фрази в компонентите.
- `src/services/` — `scoring.ts` (локално оценяване + `diagnoseDrawing` за „къде излезе“), `speech.ts`
  (Web Speech / записани файлове, `prepareForTts`), `sounds.ts` (Web Audio ефекти и тиха музика),
  `progress.ts` (чисти функции: звезди, монети, ниво, магазин, стикери, време), `adventure.ts` (отключване, буква за деня, трудни символи).
- `src/store/gameStore.ts` — Zustand + localStorage (persist версия 2, миграция от точки към монети; ръчна хидратация).
- `src/components/game/` — `WritingCanvas`, `StrokeGuide`, `useWritingExercise` (цялата логика на опит),
  `hero/HeroSvg` (8 героя с общ скелет и 9 пози; `species.tsx` — по какво се различават,
  `wearables.tsx` — рисуваните дрехи по места: глава/лице/врат/гръб/ръка), `Mascot` (`CurrentHero`), `RewardAnimation`, броячите.
  Нова дреха: запис в `data/shop.ts` със `slot` + рисунка в `WEAR_ART` (тест проверява, че има).
- `src/components/illustrations/Illustration.tsx` — илюстрациите на думите в стила на Лъвчо (SVG, офлайн).
- `src/components/games/` — обща механика: `ChoiceGame` (избор), `WriteRoundGame` (писане + „Буквен път“).
- `src/components/map/WorldMap.tsx` — пътеката с точки за един свят.

## Три отделни системи

- ⭐ звезди — колко добре е усвоен урокът (0–3 на символ, изчисляват се от `CharacterProgress`).
- 🪙 монети — печелят се от писане и игри, харчат се в магазина. Никога не се отнемат за грешка.
- Ниво — общ напредък: 1 + броят групи от `LEVELS`, в които всеки символ има ⭐.

## Правила

- TypeScript без `any`; не дублирай логика — екраните ползват `useWritingExercise`, `ChoiceGame`, `WriteRoundGame`.
- Без hardcode на уроци, текстове, аудио, цени или прагове в UI компонентите.
- Детски UX: огромни бутони, минимум текст, без наказващи съобщения, без външни линкове, без реклами/tracking.
  Родителската зона (табло и настройки) е зад задържане 3 сек. **и** задача „Колко е a + b?“.
- В лесен и нормален режим няма бутон „Готово“ — проверката е след пауза; бутонът е само в трудния режим.
- `touch-action: none` само върху полето за писане. Без мрежови заявки при писане.

## Оценяване (накратко)

Движенията на детето и шаблонът се resample-ват до точки през 2 единици. Оценката (0–100) комбинира
покритие на шаблона, точност на мастилото, посока и брой движения; липсващо парче от шаблона
(напр. чертичката на А) или излишно парче мастило (напр. 8 вместо 3) я свалят рязко.
При easy/normal се сравнява и по място, и само по форма (bbox нормализация); при hard — само по форма.
Всяка промяна на праговете трябва да минава `npm test` (включва матрица на объркване за А, Б, О, М, 1, 2, 3, 8).

## Записан глас

`src/content/voiceScript.ts` изрежда всяка изговаряна фраза с постоянно id; `npm run voice-script`
пише `docs/voice-script.csv`. Файл `public/audio/<id>.mp3` (или .m4a/.ogg/.wav) заменя синтезатора
за този текст; `scripts/audio-manifest.mjs` прави `audio/manifest.json` при build. Нова фраза в
`phrases.ts` → добави я и в `voiceScript.ts`.

## Профили

Активното дете е в `progress`; неактивните — в `stored` (`services/profiles.ts`, persist версия 4 — v4 пренася стария единствен аксесоар на мястото му).
Героят (`settings.mascot`) се пази в профила при смяна; останалите настройки са общи.

## Пътят на обучение (последователността)

Една линейна последователност от стъпки в `data/path.ts` (`CHAPTERS` → `PATH`): чертички → букви в реда на
буквара (А, О, У, Е, И, М, Л, Н…) с вмъкнати цифри, срички/думи, игри и приказки там, където детето вече
знае нужното → малките букви. `services/path.ts`: текущата стъпка е първата немината; всичко преди нея е
отворено за повтаряне, всичко след нея — заключено (игри, приказки, букви по картите, думи).
Началният екран има един голям бутон „Продължи“ → `/step/` (изпълнява текущата стъпка; `?i=N` — повторение).
`/learn/` е картата на пътя по глави. Игрите питат само за научени букви/цифри (`components/games/known.ts`).
Нова игра → запис в `FEATURES`, `GAMES` и стъпка в `AFTER` в `data/path.ts` (тест проверява реда).
