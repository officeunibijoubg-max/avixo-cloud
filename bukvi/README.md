# Буквено приключение

Интерактивна игра за таблет и телефон, с която деца на 3–7 години се учат да разпознават
и пишат цифрите 0–9 и всички 30 главни букви на българската азбука.

- **Писане с пръст, стилус или мишка** върху светъл шаблон със стрелки и номерирани движения.
- **Локална проверка на изписването**, без интернет и без AI API. Вярното изписване свети зелено,
  грешното свети червено и дава нов опит. След 2 грешки звездичка показва пътя, след 3 се пуска анимация.
- **Говор и звуци**: „А. А като автобус.“ (Web Speech API с български глас, ако устройството има такъв)
  плюс меки синтезирани звукови ефекти.
- **Точки, звезди, награди, нива и сменяем герой.** Никога не се отнемат точки.
- **Пет минигри**: Коя е буквата?, С коя буква започва?, Балони, Чуй и напиши (с „Буквен път“), Преброй и напиши.
- **Родителски екран** с научени символи, най-силните и най-трудните, точност и брой упражнения.
- **Настройки**: трудност (лесно / нормално / трудно), звук, говор, сила, висок контраст, по-големи елементи, без анимации.
- **PWA**: може да се добави на началния екран и работи офлайн след първото зареждане.

## Стартиране

```bash
cd bukvi
npm install
npm run dev          # разработка: http://localhost:3000
npm test             # тестове на оценяването и прогреса
npm run build        # статични файлове в out/, готови за всеки хостинг
npx serve out        # преглед на готовата версия
```

Прогресът се пази само в браузъра (localStorage). Приложението не събира лични данни.

Бележки за архитектурата и правилата при разработка: [CLAUDE.md](CLAUDE.md).
