# Записан глас

Сложете тук аудио файловете (`.mp3`, `.m4a`, `.ogg` или `.wav`), като всеки файл
се казва точно като `id` от сценария `docs/voice-script.csv`:

```
letter-a-intro.mp3   → „Това е А. А като автобус.“
letter-b-sound.mp3   → „Бъ“
praise-1.mp3         → „Браво!“
```

При следващия build списъкът `manifest.json` се прави сам и приложението започва
да пуска записа вместо синтезатора. Фрази без запис продължават с браузърния глас,
така че може да се записва постепенно.

## Генерирани гласове

Папките `lili/` (женски), `georgi/` и `dimitar/` (мъжки) съдържат по един запис на
фраза, генериран от `scripts/generate-voice.py`: Лили и Георги — със Supertonic 3
(лиценз OpenRAIL), Димитър — с Piper `bg_BG-dimitar-medium` (MIT, данни CC0). Запис на ръка
тук, в основната папка, заменя фразата за всички гласове.
